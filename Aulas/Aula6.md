# Aula 06 — Usuários, Segurança e Software

**FAETEC | Professor Ygor**

## Objetivos
- Compreender níveis de usuário.
- Conhecer o Windows Hello.
- Adotar boas práticas de segurança.
- Entender instalação e desinstalação de software.

## Usuários
O material-base apresenta:
- **Administrador:** privilégios elevados.
- **Usuário padrão:** privilégios mais limitados.
- **Quiosque:** utilização restrita.

## Windows Hello
Pode utilizar, conforme o dispositivo:
- PIN;
- reconhecimento facial;
- impressão digital.

## Boas práticas
- Usar contas individuais.
- Evitar privilégios administrativos desnecessários.
- Utilizar senhas fortes.
- Manter o sistema atualizado.
- Evitar programas de origem desconhecida.
- Proteger credenciais.

## Instalação de software
1. Verifique a origem.
2. Confira os requisitos.
3. Leia as opções do instalador.
4. Evite componentes desnecessários.
5. Finalize e teste o programa.

## Atividade
Pesquise no computador quais programas estão instalados e classifique-os como:
- sistema;
- produtividade;
- multimídia;
- desenvolvimento;
- outros.
