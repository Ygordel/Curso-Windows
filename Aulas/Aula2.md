# Aula 02 — Explorador de Arquivos

**FAETEC | Professor Ygor**

## Objetivos
- Compreender arquivos, pastas e unidades.
- Utilizar o Explorador de Arquivos.
- Criar, copiar, mover, renomear e excluir arquivos.
- Organizar uma estrutura de pastas.

## Conteúdo
O Explorador de Arquivos é utilizado para gerenciar arquivos e pastas do Windows.

### Conceitos
- **Arquivo:** informação armazenada.
- **Pasta:** contêiner utilizado para organizar arquivos e outras pastas.
- **Unidade:** volume/dispositivo de armazenamento.
- **Acesso rápido:** locais frequentes, favoritos e arquivos recentes.
- **Bibliotecas:** visão consolidada de conteúdos de diferentes pastas.

## Atalho principal
`Win + E` → abre o Explorador de Arquivos.

## Laboratório
Crie a seguinte estrutura:

```text
FAETEC
└── Windows
    ├── Aula
    ├── Exercicios
    └── Documentos
```

Depois:
1. Crie `atividade.txt`.
2. Renomeie o arquivo.
3. Copie para `Exercicios`.
4. Mova para `Documentos`.
5. Exclua uma cópia.
6. Recupere pela Lixeira.
7. Pesquise o arquivo pelo Explorador.
